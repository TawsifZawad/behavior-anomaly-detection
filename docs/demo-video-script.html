Demo Recording Kit

A shot-by-shot script to record a ~4½-minute walkthrough of all three modes — Analyze, Own and Live — in a single screen capture. Read the SAY line as voiceover, type the RUN line on screen, and follow the clock.

Runtime ~4:40 Record with Win+G / OBS Modes Analyze · Own · Live Take one continuous pass
Before you hit record — get a guaranteed-clean state and open two things: a terminal (Administrator PowerShell) and the dashboard file. Run python bads.py demo once so the sample scenario, alerts and dashboard are freshly generated, then close the auto-opened browser tab (you'll open it on camera).
00

Setup checklist

  • Terminal: open Windows PowerShell as Administrator (needed for Own/Live), cd into the project folder.
  • Clean state: run python bads.py demo once, then close the browser tab it opens.
  • Screen recorder: Win + G → Capture → Record, or OBS. Record the whole screen at 1080p.
  • Font size: bump the terminal font (Ctrl + Scroll) so text is readable on video.
  • Dashboard ready: know where reports\dashboard.html is — you'll open it live.
  • Optional (Live/network): if showing Suricata, have the Ubuntu VM terminal ready in a second window.

Recording tips

  • One take, but forgiving: if you fumble a line, pause 2 seconds and redo it — trim later in any free editor (Clipchamp on Windows).
  • Type commands slowly and let output settle before speaking — dead air is fine, rushing isn't.
  • Zoom the terminal + browser (Ctrl +) so text is legible at 1080p.
  • Keep it 4–5 min: if tight, shorten the dashboard walkthrough and skip the optional VM/Suricata cut.
  • Narration language: the SAY lines are English for the thesis; read them in Bangla instead if you prefer — the on-screen actions are the same.
  • Don't run demo on camera — run analyze (it's the same scenario, no retraining, and starts instantly).
